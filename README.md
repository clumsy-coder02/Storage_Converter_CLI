# Storage Converter

A small Python utility to convert and display storage sizes (bytes, KB, MB, GB, etc.).

## Description

This repository contains a simple converter program implemented in `main.py` that helps convert between common storage units and presents human-friendly output.

## Features

- Convert bytes to KB/MB/GB and back
- Human-readable formatting
- Minimal, dependency-free implementation using Python

## Requirements

- Python 3.8+

## Usage

1. Open a terminal in the project folder.
2. Run the program:

```bash
python main.py or python3 main.py

```

Adjust or inspect `main.py` to see input options or to integrate the converter into other scripts.
